PWA v5: Deploy the complete project through your existing Git-connected Netlify site or Netlify CLI. Publish directory remains public; functions remain netlify/functions. Use HTTPS (Netlify supplies it). No new environment variables, push services, or database changes are needed. On mobile, open the site in Safari or Chrome and choose Add to Home Screen / Install App when available. App installation is supported; cloud planner data still requires connectivity. The service worker caches only decorative image assets and never caches account credentials, planner data, API responses, or HTML. Test account creation, login, cloud save, account deletion, and installation after deployment.
